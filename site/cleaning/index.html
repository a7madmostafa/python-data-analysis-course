    7الـ Pipeline: كله بالترتيب، ومعاه log

    كل القرارات اللي فاتت في function واحدة، وكل خطوة بتسجّل شالت كام سطر.
    جرّب تغيّر أي قرار، وشوف بتوصل لـ sales.csv ولا لأ:

    def clean_orders(raw):
    df = raw.copy()
    df["order_date"] = pd.to_datetime(df["order_date"])
    bad = ((df["quantity"] <= 0) | (df["quantity"] > 100) |
           (df["unit_price"] <= 0) | (df["order_date"] > "2025-12-31"))
    df = df.loc[~bad]                                       # 1,501 -> 1,497
    df = df.drop_duplicates()                               # -> 1,496
    df = df.dropna(subset=["quantity"])                     # -> 1,466
    df = df.fillna({"discount": 0, "status": "unknown"})
    df["quantity"] = df["quantity"].astype(int)
    return df
