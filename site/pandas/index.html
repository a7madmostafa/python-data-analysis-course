    Pandas

    NumPy إدّانا arrays من نوع واحد.
    Pandas بتحط كذا array جنب بعض، وبتدّي كل عمود اسم، وكل سطر label: جدول.
    وأغلب يوم الـ Data Analyst بيعدّي جوّه الجدول ده.
    في الدرس ده: تقرا الجدول، وتبص عليه، وتختار منه، وتفلتره، وترتّبه.

    📓 افتح النوت بوك على Kaggle 👀 اعرض النوت بوك هنا 🗂️ داتا NileCart على Kaggle

    1Series و DataFrame

    الـ Series عمود واحد: array من NumPy، ومعاه index، يعني label لكل قيمة.
    والـ DataFrame جدول: كذا Series ليهم نفس الـ index، Series لكل عمود.

    sales.index       # RangeIndex(start=0, stop=1466): 0, 1, 2, ... by default
sales.columns     # ['order_id', 'order_date', 'customer_id', 'name', ...]
sales["revenue"]  # one column: a Series
sales["revenue"].to_numpy()   # the NumPy array underneath

    عشان كل عمود array من NumPy، كل اللي اتعلمناه في درس NumPy شغال هنا:
    الحساب على العمود كله، والـ boolean mask، والـ sum() والـ mean().
    الفرق إن الأعمدة ليها أسامي، والسطور ليها labels.

    2القراءة والكتابة

    ملف الـ CSV مجرد نص.
    Pandas بتخمّن نوع كل عمود: الأرقام بتبقى أرقام، وأي حاجة تانية بتفضل نص (object)، حتى التواريخ.
    فلازم تقولها أنهي أعمدة تواريخ:

    sales = pd.read_csv("sales.csv")
sales["order_date"].dtype     # object: text!

sales = pd.read_csv("sales.csv", parse_dates=["order_date"])
sales["order_date"].dtype     # datetime64[ns]
    الـ argumentبيعمل إيه
    parse_dates=["col"]يقرا الأعمدة دي كتواريخ
    usecols=[...]يقرا الأعمدة دي بس
    nrows=5يقرا أول كام سطر بس (تبص على ملف ضخم)
    index_col="col"يستخدم عمود كـ index
    sep=";"فاصل تاني (ملفات كتير أوروبية بتستخدم ;)
    encoding="utf-8"الـ encoding بتاع النص (النص العربي محتاج الصح)

    وعشان تكتب جدول في ملف:

    big.to_csv("big_orders.csv", index=False)   # don't write 0, 1, 2 ... as a column
    ⚠️ index=False
    لو نسيتها، الـ index (0، 1، 2، ...) هيتكتب كعمود.
    والمرة الجاية لما تقرا الملف، هتلاقي عمود زيادة اسمه Unnamed: 0.

    4الأعمدة

    sales["revenue"]                          # one name -> a Series
sales[["name", "product_name", "revenue"]]   # a list of names -> a DataFrame

    لاحظ القوسين المربعين مرتين: البرّانيين للاختيار، والجوّانيين بيعملوا list.

    أعمدة جديدة

    الحساب على الأعمدة element by element، زي NumPy بالظبط.
    و .dt بيدّيك أجزاء التاريخ، و .str أدوات النصوص، على العمود كله:

    sales["margin"] = sales["profit"] / sales["revenue"]
sales["year"]   = sales["order_date"].dt.year
sales["month"]  = sales["order_date"].dt.month
sales["first_name"] = sales["name"].str.split().str[0]   # "Yasmin Mostafa" -> "Yasmin"

    تغيير الاسم والنوع، والمسح

    tidy = (sales
        .rename(columns={"product_name": "product"})
        .astype({"quantity": "int64"})        # safe: sales.csv has no NaN
        .drop(columns=["first_name"]))
    ➕ بيرجّعوا جدول جديد
    rename و astype و drop مبيغيّروش sales نفسه.
    بيرجّعوا جدول جديد، فلازم تحطه في متغير (tidy = ...) عشان تحتفظ بيه.
    والقوسين حوالين السلسلة بيخلّوك تكتب كل خطوة في سطر.

    5loc و iloc: بالـ label ولا بالمكان؟

    iloc[...]: بالمكان

    0، 1، 2، ... زي الـ list.
    الـ i معناها integer position.

    loc[...]: بالـ label

    أي حاجة موجودة في الـ index.

    مع الـ index العادي (0، 1، 2، ...) الاتنين شكلهم واحد.
    خلّي order_id هو الـ index، والفرق يبان:
    الملف مش مترتّب بـ order_id، فأول سطر هو الأوردر 10002، والتاني 10001.

    s = sales.set_index("order_id")
s.iloc[0]        # position 0: order 10002, Fatma Hassan
s.loc[10001]     # label 10001: the second row, Yasmin Mostafa
    ⚠️ الـ slice: loc بيشمل الآخر، و iloc لأ
    iloc[0:3] زي Python: الأماكن 0 و 1 و 2، والآخر مش داخل.
    loc[10002:10003] من الـ label ده للـ label ده، الاتنين داخلين، وبترتيب السطور في الجدول مش ترتيب الأرقام.
    فطلعوا 4 سطور: 10002، 10001، 10004، 10003.

    تغيير القيم: دايمًا من خلال loc

    sales.loc[sales["region"] == "Unknown", "region"] = "Not given"   # rows, column = value

sales[sales["region"] == "Unknown"]["region"] = "Not given"  # chained: changes a temporary copy

    السطر التاني بيختار السطور، وبعدين العمود، في خطوتين.
    فالتغيير بيروح على نسخة مؤقتة، مش على sales.
    في Pandas 2 كان ساعات بيشتغل وساعات لأ، ومعاه SettingWithCopyWarning.
    ومن Pandas 3 عمره ما بيغيّر الجدول، و Pandas بتطلّع warning اسمه ChainedAssignmentError.
    الحل واحد: df.loc[rows, column] = value، في خطوة واحدة.

    6الفلترة

    نفس الـ boolean mask بتاع NumPy، بأسماء الأعمدة:

    mask = sales["status"] == "completed"    # a Series of True / False, one per row
done = sales[mask]                        # 1,074 of 1,466 rows

    اختصارات

    sales[sales["status"].isin(["returned", "cancelled"])]   # 187: one of several values
done[done["revenue"].between(1_000, 5_000)]          # 357: both ends included
sales[sales["name"].str.contains("Mostafa")]           # 222: text that contains ...

sales.query("status == 'completed' and revenue > 100_000")   # 43: the condition as a string
sales.query("revenue > @cutoff")                            # @ uses a Python variable

    وتقدر تفلتر وتختار أعمدة في loc واحد:

    sales.loc[(sales["status"] == "completed") & (sales["region"] == "Canal"),
          ["order_date", "name", "product_name", "revenue"]]

    done.sort_values("revenue", ascending=False).head()          # the 5 biggest lines: all laptops
done.sort_values(["category", "revenue"], ascending=[True, False])   # ties in the first broken by the second
done.nlargest(3, "profit")                                # shortcut for sort + head
s.sort_index()                                           # by the index labels: 10001, 10002, 10003 ...
    💡 ده الـ argsort
    في درس NumPy، argsort طلّع نفس أكبر 5 أوردرات: كلهم لابتوب.
    sort_values هو الـ argsort ده، متطبّق على كل الأعمدة مرة واحدة، فالسطر بيفضل متماسك.

    8أخطاء شائعة

    ✗ تنسى parse_dates

    التاريخ بيفضل نص، و .dt.year يطلّع error.

    ✓ parse_dates=["order_date"]

    واتأكد بـ df.info().

    ✗ df["a", "b"]

    KeyError: Pandas فاكرة إن ده اسم عمود واحد.

    ✓ df[["a", "b"]]

    list جوّه الأقواس.

    ✗ loc بالمكان أو iloc بالـ label

    بيشتغل بالصدفة مع الـ index العادي، ويبوظ أول ما تغيّره أو ترتّب.

    ✓ اعرف الـ index بتاعك

    label؟ loc. مكان؟ iloc.

    ✗ df[cond]["col"] = value

    بيغيّر نسخة، والجدول زي ما هو.

    ✓ df.loc[cond, "col"] = value

    خطوة واحدة.

    ✗ df.drop(columns=[...]) وخلاص

    الجدول الأصلي مبيتغيّرش.

    ✓ df = df.drop(columns=[...])
