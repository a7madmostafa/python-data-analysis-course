# Python Data Analysis Course: the website side

A self-paced Data Analysis course for the **ZeroGrad** website, built alongside a live course
"Data Preparation, Exploration & Visualization".
The repo root is laid out for students (see the root README); this folder is the machinery behind
zero-grad.com and Kaggle. Sister repo of `ML Course`; every ZeroGrad course is its own repo next to the others in `D:\Ahmad\00\`.

Every lesson has two parts:

1. **The lesson page** (`website/site/<lesson>/index.html`): the explanation, figures, diagrams and interactive widgets, in Arabic, same look as the ML course.
   Lessons 1–8 are hand-written HTML; from Matplotlib on, each page's content is a fragment in `website/build/pages/<lesson>.html`
   and `website/build/lesson_page.py` wraps it in the shared shell (`pages/_shell.css`, top bar, hero, table of contents, pager).
2. **The solved notebook** (in the study folders, e.g. `2-numpy/numpy.ipynb`; `course.json` maps each lesson to its file): all the code with outputs, published on Kaggle and rendered to `website/site/<lesson>/notebook/index.html`.

No quizzes, no labs, no unsolved exercises.

## Build

Run from the repo root:

```bash
python website/build/make_orders_data.py              # NileCart tables in data/nilecart (seed 42)
python website/build/export_site_data.py              # website/site/assets/data/*.js
python website/build/build_intro.py                   # write + execute a lesson's notebook
python website/build/build_linalg.py
python website/build/build_stats.py
python website/build/build_numpy.py
python website/build/build_pandas.py
python website/build/build_grouping.py
python website/build/build_cleaning.py
python website/build/build_viz.py
python website/build/lesson_page.py --all            # pages from Matplotlib on, from website/build/pages/<lesson>.html
python website/build/render_notebook.py --all         # website/site/<lesson>/notebook/index.html
python website/build/make_dataset_metadata.py --push  # Kaggle dataset About, column notes, cover
python website/build/export_to_site.py                # copy website/site/ to ../zero-grad/site/courses/da
```

Pages use site-absolute links (`/courses/da/...`), so preview them inside the zero-grad site: export, then serve `../zero-grad/site` and open `/courses/da/`.
Deploy from the zero-grad repo (see its README). The courses page, home page and sitemap there link to the course.

Notebooks are generated by `website/build/build_<lesson>.py`: edit the script, not the `.ipynb`.
Numbers in the lesson text are hard-coded, so after a rebuild check them against the notebook outputs.
