    Plotly

    Plotly بترسم charts تفاعلية: hover عشان الأرقام، واسحب عشان تعمل zoom، ودبل كليك يرجّعها، وكليك على الـ legend يخبّي series.

    4الشكل: الـ update_*

    الـ magic underscore: xaxis_title="X" هي نفسها xaxis=dict(title="X").

    fig.update_layout(title=dict(text="...", x=0.5), xaxis_title="...", template="simple_white",
                  legend=dict(orientation="h", y=-0.2))                  # everything outside the traces
fig.update_xaxes(range=[0, 30], showgrid=False)                             # = set_xlim
fig.update_yaxes(tickprefix="$", type="log")                                # = set_yscale("log")
fig.update_traces(marker=dict(size=10, opacity=0.7))                         # every trace
fig.update_traces(line_width=4, selector=dict(name="Manhattan"))             # one trace

fig.add_hline(y=1000, line_dash="dot", annotation_text="1,000 listings")      # = axhline
fig.add_vrect(x0="2018-11-01", x1="2018-12-31", fillcolor="red", opacity=0.15)   # = axvspan
fig.add_annotation(x=..., y=..., text="Peak", showarrow=True)                 # = annotate

    10مطبات

    ✗ مفيش global state

    مفيش plt.gca(): امسك الـ fig دايمًا.

    ✗ px.bar مبيجمّعش

    groupby الأول، أو px.histogram بـ histfunc.

    ✗ أرقام كـ strings

    المحور بيبقى categorical. اجبره: update_xaxes(type="category") أو حوّل النوع.

    ✗ كل سطر بيسافر مع الرسمة

    48,000 نقطة بطيئة وتقيلة. جمّع أو خد sample قبل ما ترسم، أو render_mode="webgl" للداتا الكبيرة.

    ✗ ترتيب الـ traces

    هو ترتيب الرسم وترتيب الـ legend.

    ✗ الرسمة فاضية في Jupyter؟

    ظبّط pio.renderers.default: "notebook"، "vscode"، "browser".
