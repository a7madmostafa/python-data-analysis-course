2الفكرة كلها: الـ script بيعيد من الأول

Streamlit بيشغّل الـ script بتاعك من فوق لتحت، وبيشغّله تاني من فوق كل مرة حد يلمس widget. كل widget ببساطة بيرجّع قيمته الحالية:

age = st.slider("Age", 0, 80, 30)        # an int, like input(), but in a browser
st.write("Passengers older than", age, ":", (df["Age"] > age).sum())
touch a widget → the whole script runs againمفيش callbacks تربطها: حرّك الـ slider، الـ script يعيد بالـ age الجديد، والصفحة تتحدّث

3نمط الـ dashboard

تقريبًا كل dashboard ليه نفس الـ 3 خطوات:

1. widgetsفي الـ sidebar، بترجّع اختيارات المستخدم.
2. mask لكل widgetboolean، تتجمع بـ &، فيطلع DataFrame متفلتر.
3. أرقام ورسوماتبتتحسب من الـ DataFrame المتفلتر بس، عمرها ما تلمس df.
classes = st.sidebar.multiselect("Class", [1, 2, 3], default=[1, 2, 3])
ages = st.sidebar.slider("Age", 0, 80, (0, 80))                   # a tuple -> a range slider
view = df[df["Pclass"].isin(classes) & df["Age"].between(*ages)]

if view.empty:
    st.warning("No passenger matches these filters.")
    st.stop()                                                        # nothing after this line runs
st.metric("Passengers", len(view))
st.plotly_chart(px.histogram(view, x="Age"))
⚠️ 177 راكب من غير سن
between بيرمي الـ NaN من غير ما يقولك. عشان كده الـ app فيه checkbox "Keep passengers with unknown age": جرّبه فوق.

4الـ Cache: متعملش الشغل البطيء كل مرة

عشان كل كليك بيعيد الـ script كله، pd.read_csv بيشتغل مع كل كليك برضه. مع ملف كبير أو database أو API، ده بطيء. @st.cache_data بيفتكر الـ function رجّعت إيه لنفس الـ arguments. 09_cache.py بيخلّي الـ loader ينام ثانيتين عشان تحس بالفرق:

@st.cache_data               # the only change: one line above the function
def load_data(path):
    return pd.read_csv(path)

st.cache_data.clear()        # e.g. after the file changed on disk

الـ Forms: widgets كتير، rerun واحد

جوه with st.form("name"): مفيش حاجة بتعيد لحد ما زرار الـ submit يتداس. استخدمها لما المستخدم بيملا كذا خانة، والمهم التركيبة النهائية بس.

with st.form("filters"):
    classes = st.multiselect("Class", [1, 2, 3], default=[1, 2, 3])
    ages = st.slider("Age", 0, 80, (0, 80))
    submitted = st.form_submit_button("Apply")     # the only rerun

كذا صفحةالـ entrypoint هو البرواز والصفحات هي الصور: اللي streamlit_app.py بيرسمه (فلاتر الـ sidebar) بيظهر في كل صفحة، و st.navigation([...]).run() بيشغّل ملف الصفحة اللي اتداس عليها. الداتا المتفلترة بتتشارك بـ st.session_state.
Theme.streamlit/config.toml بيحدد ألوان كل الـ widgets: primaryColor، و backgroundColor، و secondaryBackgroundColor، و textColor، و font.
charts.pyfunction لكل رسمة، بيستخدمها النوت بوك والـ app الاتنين: الرسمة تتعدّل في حتة واحدة.

7uv، والنشر ببلاش

الخطوةالأمر
تبدأ مشروعuv init my-app && cd my-app
تضيف packagesuv add streamlit pandas plotly (بيكتب pyproject.toml و uv.lock)
تجهّز مشروع موجودuv sync
تشغّل أي حاجة فيهuv run streamlit run streamlit_app.py

uv.lock بيسجّل النسخة بالظبط لكل package. اعمله commit مع الكود، وكل جهاز (لابتوب زميلك، سيرفر النشر) يبني نفس البيئة. من غيره، pip install pandas هيجيب نسخة تانية السنة الجاية، والـ app ممكن يبوظ.

Streamlit Community Cloud

1. GitHubارفع فولدر الـ app، ومعاه pyproject.toml و uv.lock والداتا.
2. Sign inعلى share.streamlit.io بحساب GitHub.
3. Create appاختار الـ repo، والـ branch، ومسار streamlit_app.py، و Python 3.13 من Advanced settings.
4. Deployبعد دقيقة الـ app شغال على https://<name>.streamlit.app.

بعد كده كل git push بيحدّث الـ app لوحده. الأخطاء والـ print() في Manage app → logs. الـ apps المجانية بتنام بعد كام يوم هادي، وأول زائر بيصحّيها.
